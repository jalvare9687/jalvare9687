### Selected work

**[Stockly](https://github.com/jalvare9687/Stockly)** — Inventory health dashboard
Spring Boot backend surfacing turnover, supplier fill-rate, and lead-time KPIs over a PostgreSQL schema modeling menu items, recipes, ingredients, and inventory lots. Eliminated N+1 query patterns, added paginated endpoints, and consolidated error handling into a global exception handler returning a structured error type. Originated as a UGAHacks NCR Voyix submission; independently rebuilt since.
`Java` `Spring Boot` `PostgreSQL` `Docker`

**[robo-fighters](https://github.com/jalvare9687/robo-fighters)** — Adaptive curriculum for RL fighting-game agents
A controlled experiment: does training a PPO agent against an adaptive AI Director beat training against a static opponent? The Director-trained agent won head-to-head 42–18, but generalized *worse* to unseen opponents — the difficulty curriculum saturated at maximum within 18 rounds. Built during a FanDuel-sponsored REU, 1 of 7 selected.
`Python` `PPO` `Gymnasium` `Stable-Baselines3`

**StreetAid** — Real-time food and resource access platform
Addresses food desert access in Atlanta, where one in four residents is affected, with resource lookup by zip code. I built the Spring Boot services and PostgreSQL schema, wired the Google Maps API into the browser client, and delivered AI-generated resource summaries through the Claude API. Presented at Hacklanta.
`Java` `Spring Boot` `PostgreSQL` `Google Maps API`
